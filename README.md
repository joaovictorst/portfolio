# Portfólio

Portfólio pessoal com tema Windows 98, construído com Next.js e TypeScript.

A interface simula um desktop com janelas arrastáveis, ícones, taskbar e menu Start, recriando a estética do Windows 98 no browser.

## Stack

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [98.css](https://jdan.github.io/98.css/) — biblioteca de estilos que replica a UI do Windows 98
